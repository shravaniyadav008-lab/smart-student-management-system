\# Smart Student Management System



\## About the Project

The Smart Student Management System is a web-based application developed using Python Flask. It helps manage student information through a simple and user-friendly interface.



\## Features

\- Student Management

\- Course Management

\- Attendance Management

\- Results Management

\- Dashboard with student statistics

\- Login and Registration

\- Settings Page



\## Technologies Used

\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- JavaScript

\- Chart.js



\## Installation and Setup



1\. Clone the repository:

&#x20;  ```bash

&#x20;  git clone https://github.com/shravaniyadav008-lab/smart-student-management-system.git

&#x20;  ```



2\. Open the project folder:

&#x20;  ```bash

&#x20;  cd smart-student-management-system

&#x20;  ```



3\. Create a virtual environment:

&#x20;  ```bash

&#x20;  python -m venv venv

&#x20;  ```



4\. Activate the virtual environment on Windows:

&#x20;  ```bash

&#x20;  venv\\Scripts\\activate

&#x20;  ```



5\. Install dependencies:

&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



6\. Run the application:

&#x20;  ```bash

&#x20;  python run.py

&#x20;  ```



7\. Open this URL in your browser:

&#x20;  `http://127.0.0.1:5000`
